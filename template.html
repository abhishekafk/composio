The agent

A six-step pipeline. Humans checked it at the points marked in amber.

1 · INPUT100 apps

The list from the brief, with its docs hints.

2 · SEARCHFind vendor docs

Tavily search for each app and each field.

3 · CRAWLRead the pages

A zero-credit crawler with a Jina reader fallback when sites block bots.

4 · EXTRACTAnswer with a quote

Groq gpt-oss-120b, falling back to 20b. Every answer must cite a vendor quote.

5 · VERIFYRules and registry

Quote must support the claim. MCP checked against the MCP Registry. Unsupported "none found" becomes unknown.

6 · TIERLabel the proof

Each field is verified, hand-checked, inferred or unknown.

What I did not do

I used Composio's catalog API to see which apps already have a toolkit (81 of 100 do). I did not build the agent on Composio's SDK or MCP, and I did not use browser automation for verification. Free-tier limits and time pushed me to Groq, Tavily and Jina instead.

Limits

What the numbers do not prove.

Read this before trusting the scores
  • 48 gold apps is small. The v1 to v4 intervals overlap, so 73% to 81% is a trend, not proof.
  • Gold was built partly with a research agent. 44 of 48 labels were blind. It has no "no MCP" labels, so those claims are unscored.
  • The tiered record and the api_key vs bearer check (+3 points overall) were designed after seeing the scores.
  • v4 committed to an answer on about 56% of fields (45.2% overall divided by 80.9%).
  • 63 apps look buildable, but only 7 are proven. 56 still need a signup check.
Disclosures
  • Three free Groq keys were rotated to stay inside rate limits. 120b and 20b were mixed, with 4 fallback failures.
  • Jina reader fetched pages after bot blocks (Salesforce Commerce Cloud, Sentry, PitchBook, Otter AI). Harvest blocked robots.
  • 32 access answers have no quote or URL.
  • Shopify and Airtable access were corrected after the run and still await a human check.
  • API breadth is not captured. The data has the API type (REST, GraphQL and so on) only.
  • Built with Antigravity as the coding helper. Free tiers only.
